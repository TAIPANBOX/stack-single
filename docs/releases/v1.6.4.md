# stack-single 1.6.4

A patch release. A re-run of the installer no longer restarts wardryx for nothing.

## Upgrade first

**Run `./install.sh` again from this release.** No image moves, and no container is recreated by it.

## What changed

- **A second run leaves `policy.yaml` where it is.** With the risk hold and the budget hold both on, the risk block took itself out and went back below the budget block, so every run rewrote the file and restarted wardryx. A risk block that already says the right thing now stays put. 1.6.3 showed it on the second run on a real box, and a box with one block never does.
- **The README names what a restart of vouchryx costs.** It keeps its working key in memory, custody keeps at most four certified keys live for up to 72 hours and ten minutes, and a restart past the fourth leaves it with no key until the oldest ages out. A release that changes `init-volumes` restarts vouchryx too, as 1.6.3 does. It recovers alone, and callers on a static key are not touched.
