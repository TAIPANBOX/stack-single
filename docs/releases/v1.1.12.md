# stack-single 1.1.12

Felyx, the console's copilot, is governed like any agent by default, and a
verified delegation plane is one variable away.

## Felyx through the box's own gateway

The console moves to `genaryx-console:v1.1.17` (genaryx#83). Felyx now asks
its model through `http://tokenfuse-gateway:4100`, by service name, under
`agent://<RECORD_TRUST_DOMAIN>/genaryx/felyx`, so every question is priced,
budgeted and policy-checked. Its residency check accepts that one name,
resolved on every connection to private addresses only. No key ships: set
`GENARYX_COPILOT_KEY` in `.env` and restart the console. Invariant 16, gated
by `scripts/felyx-through-the-gateway.sh`. Measured 2026-09-27 on a Linux
Docker network with a stub gateway: `local: true` and the question reached the
gateway; without the allow-list the endpoint was refused.

## An opt-in delegation plane (#76)

`WITH_DELEGATION=1 ./install.sh` adds vouchryx
(`ghcr.io/taipanbox/vouchryx:v0.1.0`) behind `--profile delegation` and turns
on the gateway's delegation door, so an `on_behalf_of` chain is verified
rather than trusted. It needs your identity provider in
`VOUCHRYX_TRUSTED_ISSUERS`, or `WITH_DELEGATION_DEMO_ISSUER=1` for a labelled
demo issuer; with neither, the installer refuses before starting anything. Keys
are minted once, never printed, and reused. Review found, before release, that
a root-owned 0700 `./delegation` mounted into both containers stopped both on
Linux (Docker Desktop on macOS hides it): vouchryx now owns `./delegation`
alone and the gateway reads `./delegation-public` (invariant 15, new gate
`scripts/delegation-dirs-are-split.sh`), measured red then green on Debian 13.

## Not in this release, said plainly

- `install.sh` with `WITH_DELEGATION=1` end to end on a Debian box: the
  directory layout and both containers were run on Debian, the whole installer
  was not.
- Felyx with a real key through this path.
- The gateway still forwards a caller's `Authorization` header to the provider,
  which on a delegated call carries the delegation token; tracked separately in
  tokenfuse.
