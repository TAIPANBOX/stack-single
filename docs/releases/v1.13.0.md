# stack-single 1.13.0

A minor release. The FinOps console reads the gateway's spend; a piped install runs only a signed release; the console can revoke a delegation with a key of its own; every install asks the box who can write what on the bus; every service has a memory ceiling; a lost `.env` is no longer regenerated over a stack. It also carries the installer's broker ask that asks again after a hold (invariant 79, #195), merged after 1.12.0.

## Upgrade first

1. **The install line changes.** A piped install is now `curl -fsSL https://github.com/TAIPANBOX/stack-single/releases/latest/download/install.sh | bash`, and it runs the latest release's tree only behind its cosign signature from this repository's release workflow on that tag (invariant 84, #199). This is the first release that carries that signed tree; a piped install of 1.12.0 is refused, because 1.12.0 carries no bundle. A clone runs as before. `INSTALL_FROM_MAIN=1` installs main, unsigned, by name. Each release is signed by `.github/workflows/release.yml` on its tag into a draft, and a person publishes it.
2. **Run the installer.** Every container is recreated once, because every service now has a `mem_limit` (invariant 85). keyryx retires the oldest working key of vouchryx at its bound (invariant 72), so this costs no certified key. A second run recreates nothing.
3. **New on the box:** `focus-export` runs by default (no profile) over both doors, into `focus/gateway` and `focus/gateway-openai` of the `focus` volume; `CONSOLE_REVOKE_KEY` in `.env` and `console-revoke/revoke.key` (uid 10001, 0400). A running FinOps console is re-upped with the focus folders read only and `-focus-replace-generated`: **its first import of a real export replaces the generated demo estate (board, tasks, sprints, anomalies, forecasts).**
4. **Memory ceilings are per service, and 1 GiB for the readers of the whole bus or trace** (idryx, idryx-detect, verdryx-slo, verdryx-drift, record-seal). On a box whose bus has grown for months, check `docker stats` before upgrading and raise a ceiling in `compose.yaml` if one of them is near it.
5. **Going back to 1.12.0** needs nothing special: the rollback index stays 1.

## What is new

- **The money reaches CostCrew** (invariant 80, #197, closes #61). focus-export writes each door's spend, one file per door rewritten whole, and the FinOps console reads both folders at start and every 15 minutes. A door that has served nothing yet gets the other door's header alone, because costcrew v0.10.2 refuses a folder with no `*.csv` and with it the whole import.
- **components.json is true** (#197): verdryx-drift is a job a person starts, and manifest-is-true.sh refuses a scheduled routine behind a profile the installer does not start.
- **A lost `.env` is not regenerated over a stack** (invariant 81, #198, closes #62). README: "Back up .env".
- **The console's revoke button** (invariant 82, #198), with a key of its own beside the operator's.
- **Every producer is asked on the box** (invariant 83, #198): an install check that each plane can write its own stream and nothing else on the bus.
- **Every service has a memory limit** (invariant 85, #198).
- **A piped install takes a signed release** (invariant 84, #199).
- **The broker ask asks again after a hold** (invariant 79, #195).
