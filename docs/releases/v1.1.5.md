# stack-single 1.1.5

The two money-plane images move together to TokenFuse 1.0.3. The gateway
retains run and unit reservations when a request is cancelled after dispatch,
reads complete SSE events, and nets cached tokens correctly.
On startup, the gateway seeds a unit's current-month spend from the control
plane and replays a bounded telemetry queue after transport recovery. The
control plane reports a run that goes quiet after an observed cadence. The
event-file open failure is now visible to the operator.

## The pinned set, 2026-09-19

As in 1.1.4, with `tokenfuse:v1.0.3` for the gateway and focus exporter and
`tokenfuse-control-plane:v1.0.3` for the control plane. No other image moves.

## Limits

- No install or reboot was run on this pinned set. The earlier appliance run
  and this release's static gates do not prove it on a fresh box.
- A gateway restart still loses the process-local run ledger and retained
  reservations. There is no reconciliation route for an unknown provider
  outcome.
- A provider `send` error can still release a reservation after the provider
  received the call. Clean streams without final usage remain under review.
- The control plane has no explicit run-finished signal, so a completed run
  without an outcome tag can produce one medium `run_stalled` incident.
