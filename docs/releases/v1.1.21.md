# stack-single 1.1.21

The FinOps console joins as an opt-in add-on, and tokenfuse moves to `v1.7.0`.

## The FinOps console, opt-in (#92 to #96, #98)

- **New compose profile `finops`** (#92): `costcrew-init` (a busybox one-shot that
  prepares the console's own volume, so the add-on never edits `init-volumes`)
  and `costcrew`, the console, published on `127.0.0.1:8321` only, with a new
  `costcrewdata` volume and its own `costcrew.ndjson` stream on the shared bus.
  Nothing in `install.sh` starts it; a person starts it with
  `docker compose --profile finops up -d costcrew`. Held by invariant 24 and
  `scripts/finops-is-opt-in.sh`.
- **Pinned to costcrew `v0.4.0`** (#93, #94): `${COSTCREW_IMAGE:-ghcr.io/taipanbox/costcrew:v0.4.0}`,
  and the README names the tag.
- **A writable temp for the console** (#95): the container keeps its read-only
  root and gets a 128 MB `tmpfs` at `/tmp`, so SQLite can vacuum and spill
  temporary files. Before this, the first start after upgrading costcrew logged
  that the database could not be vacuumed (`disk I/O error (6410)`). The gate
  refuses a read-only console with no writable temp, an unbounded tmpfs, or a
  `TMPDIR` inside the read-only root.
- **No owner quotes in public text** (#95, #96): a new gate,
  `scripts/no-owner-quotes.sh` (invariant 25), refuses quotes and attributions
  of decisions in tracked text; #96 lets it find the repository from inside a
  git hook.
- **The teeth harness clears a hook's git environment** (#98) around the scratch
  repository one case builds, so the case judges the scratch tree and not the
  repository being pushed.

## Upgrading the console (if the `finops` profile is in use)

- Everybody signs in to the console again once; old sessions end at the first
  start of costcrew v0.4.0.
- The console's files become private (0600); the bus stream stays readable.
- Requests over 1 MiB are refused with 413.


## What moves with tokenfuse

- **tokenfuse `v1.6.1` -> `v1.7.0`**: `tokenfuse-control-plane`, the gateway,
  `focus-export` and `tokenfuse-mcp-broker`. The tag is v1.7.0 on tokenfuse
  `ac2ec33`, published 2026-10-08 for amd64 and arm64 (index
  `sha256:6ebebf41ee38b113d92d5bbcf18d0edba0210689b35630c192949a6f640b18e4`
  for `tokenfuse:v1.7.0`,
  `sha256:1eaed648c4878b25f77984846b6e76ff8f0fd88b5e10df41a5905e6c61c6c39e`
  for `tokenfuse-control-plane:v1.7.0`, read with
  `docker buildx imagetools inspect`). TokenFuse's own notes:
  `docs/releases/v1.7.0.md` in that repository.
  - **A price-book row for every listed Claude id, and for the current Gemini
    models on Vertex AI** (tokenfuse#366, #369). A call to one of those ids
    used to settle at the 15 / 75 fallback rate and now settles at its list
    rate.
  - **A Gemini thinking call is charged its reasoning tokens** (tokenfuse#367).
    Output is the larger of `completion_tokens` and `total_tokens` less
    `prompt_tokens`; for OpenAI the two are equal.
  - **`x-fuse-price` on every metered answer**, streamed ones included.
  - **`TOKENFUSE_PRICE_BOOK`**, an optional operator price file. This
    launcher does not set it.
  - **Two FOCUS export columns, appended last**: `x_key_id` and
    `x_block_reason` (tokenfuse#368). A row refused for identity is now filed
    under `key:<key_id>` with `x_agent_id` empty, not under the agent it
    claimed.

No other pin moves. `TOKENFUSE_IMAGE` and `TOKENFUSE_CLOUD_IMAGE` still
override the defaults. TokenFuse changed no Dockerfile between v1.6.1 and
v1.7.0, so the binary paths `compose.yaml` names are unchanged.

## Upgrading

- **Nothing to configure.** TokenFuse names no new required setting. Every
  `TOKENFUSE_*` name `compose.yaml` hands the gateway, the control plane or
  the broker is still read at v1.7.0, and nothing frozen in TokenFuse's
  `compat/1.0.json` moves. Re-running `install.sh` pulls the new
  images; `.env` is not rewritten.
- **A call may cost less, or more, than on v1.6.1.** A listed Claude or Gemini
  id that settled at the fallback now settles at its list rate, and a Gemini
  thinking call now pays for its reasoning. The run-budget ceiling
  (`RUN_BUDGET_CEILING_USD`, 5.00 by default) is unchanged, and a run sized
  against the fallback rate now has more room under it.
- **`focus-export`'s CSV files gain two columns at the end.** A consumer that
  reads columns by name needs nothing. CostCrew's FOCUS reader reads by name
  and refuses only a missing column. A consumer that checks the exact header
  will see the two new ones.

## Not proven

- **A single-box install with this pin.** None was run. `install.sh` was not
  re-run here.
- **The new rates through this stack.** No live model call was made here.
  TokenFuse's own notes say no live call to any provider was made for its
  release either; its rows are held by its tests.
