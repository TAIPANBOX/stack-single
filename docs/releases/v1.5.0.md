# stack-single 1.5.0

A minor release. The box moves to this wave's service releases, a read of the web passes the TokenFuse MCP broker so a run is labelled from what it did, and the console reaches the policy archive and the gateway's traces its proofs run on.

## Upgrade first

1. **Run `./install.sh` again from this release.** A box with its own operator files names them as before (`CLIENT_KEYS_FILE=... IDENTITY_MAP_FILE=...`). A re-run keeps the Scopyx key it minted and moves the agent and the scope with the trust domain.
2. **`WITH_EGRESS` or `WITH_BROWSER` with `WITH_AGENT_TOKENS=0` is refused before anything is installed.** The broker's gateway key exists only with agent tokens.
3. **An agent reads the web through the broker.** Scopyx and the browser left the `agents` network. An agent calls `http://tokenfuse-mcp-broker:4200/mcp` with `X-Fuse-Mcp-Upstream: scopyx`, `X-Fuse-Agent-Id`, `x-fuse-run-id` and `params._meta: {"scopyx/key": "{{secret:scopyx_key_<agent>}}"}`. The README section "How an agent reads the web" has the client.

## What changed

- **A run is labelled from the act (G2.1).** The broker runs under `typed` and both egress profiles and classifies Scopyx as `web`. One Scopyx key per agent sits in the broker's vault. Invariant 55, gate `scripts/scopyx-reads-go-through-the-broker.sh`, 27 teeth cases (#159).
- **The console's proofs have their inputs.** The console is told where the policy archive and the gateway's traces are, and can read both. `init-volumes` makes every file in the archive 0640 on each up, so a version an earlier wardryx wrote stays readable. Invariant 56, gate `scripts/console-proofs-have-their-inputs.sh`, 18 teeth cases (#160).
- **The console's incident loop.** `genaryx-console:v1.7.5` assembles a case file for an incident, proves a candidate policy and budget, routes typed remedies to a person and seals a case.

## Measured

- On forge with wardryx v2.4.1 the console could not open an archive file and `wardryx replay` answered "not archived" for all 490 decisions; run as the owner it reproduced 490. That is the defect the 0640 step closes.
