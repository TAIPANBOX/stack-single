# stack-single 1.1.14

Pins only: three planes move to releases that fix what the 2026-09-27 lab
runs found.

## What moves

- **TokenFuse and its control plane `v1.4.0` -> `v1.4.1`.** A delegation
  credential (`Authorization: DPoP ...`) is no longer forwarded to the model
  provider; a restarted gateway seeds each run's spend from the Cloud before
  its first call, so a run budget survives a `docker compose restart`; queued
  telemetry is not overtaken by a fresh send during an outage.
- **wardryx `v1.1.1` -> `v1.1.2`.** A refusal for an approval token's sub-cent
  cost ceiling prints the amounts instead of "$0.00 exceeded by $0.00".
- **Console `v1.1.17` -> `v1.1.19`.** Felyx reads every money value as dollars.
