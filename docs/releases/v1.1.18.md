# stack-single 1.1.18

Pins only: the console moves to `genaryx-console:v1.1.25`.

## What moves

- **Console `v1.1.19` -> `v1.1.25`** (built by stack-k8s tag v1.1.25 from
  genaryx `ecaeb6a`: genaryx#88, #89, #90).
  - Felyx, the console's copilot, reads budgets from a `budgets` tool (the
    Cloud's own run and unit budgets with their spend) instead of inferring
    them from alerts, which list a run only once it is near or over its limit.
  - Every draft answer is checked against that answer's own tool results; a
    budget statement no tool returned is sent back once for revision.
  - The Money panel's runs table shows every run budget the Cloud holds, not
    only the ones that alerted.

## Measured

On forge (k3d, stack-k8s), 2026-10-05, not on a single box: on console v1.1.19
Felyx called a budgeted run unbudgeted and gave one run's cap to another; on
v1.1.25 the same two questions matched the Cloud's `GET /v1/budgets`, read the
same minute, exactly.

## Not proven

No single-box install was run with this pin. The image is the same one stack-k8s
pins, and the console reads the Cloud the same way in both launchers, but
`install.sh` itself was not re-run here.
