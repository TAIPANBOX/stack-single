# stack-single 1.1.10

The console moves to 1.1.14 and the policy plane to 1.1.0.

## What changed

- **`genaryx-console:v1.1.14`** (was v1.1.1), for the console and the
  `verdryx-drift` routine. It carries genaryx#81: Felyx's model calls name the
  agent making them (`x-fuse-agent-id`), so a TokenFuse gateway enforcing
  policy can govern the console's own copilot instead of refusing it.
- **`wardryx:v1.1.0`** (was v1.0.3). It adds `POST /v1/filter-tools`, which
  TokenFuse calls only when `TOKENFUSE_TOOLS_PRUNE=shadow`; the decision path
  is unchanged.

## Measured

On 2026-09-27 the same two images ran together with TokenFuse 1.3.0 on a
three-node cluster (stack-k8s 1.1.15's set): its verify and security checks
passed in full.

## Upgrade

Re-run `install.sh` on the box. The console's and wardryx's images are pulled;
`.env` is left as it is.

## Not in this release, said plainly

- A full `install.sh` run with this pinned set was not made on a box; the
  images ran on a cluster.
- Felyx still defaults to a local Ollama the box does not ship.
