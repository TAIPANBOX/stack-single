# stack-single 1.14.0

A minor release that moves three planes to their new releases and drops a workaround the FinOps console no longer needs. It also documents how to check the bootstrap of a piped install before it runs.

## Upgrade first

1. **Run the installer.** No new file, no new setting, no new network. Four images move by tag and digest; their containers are recreated. The rollback index stays 1.
2. **The FinOps console moves to costcrew v0.11.0.** It reads an empty export folder as nothing to import and replaces its generated estate only for an import that brings spend (costcrew#183), so focus-export no longer writes the other door's header into an idle door's folder. A header-only file 1.13.0 left in an idle folder is replaced by that door's first real export; until then the console reads it as a door with no calls.
3. **From 1.12.0 straight to 1.14.0** takes everything 1.13.0 brought as well (its notes: the money reaches CostCrew, the `.env` guard, the console's revoke key, the bus probe, per-service memory limits, the signed tree for a piped install). The first real import replaces the console's generated demo estate.
4. **Going back to 1.13.0 needs nothing special.** The rollback index stays 1.

## What is new

- **The pins** (#201): the four images above.
- **No header file for an idle door** (#201, invariant 80): the gate requires costcrew v0.11.0 or later and an idle door's folder to stay empty.
- **Check the bootstrap before it runs** (#201): the README shows how to fetch the release's `install.sh`, tree and bundle, verify the tree with `cosign verify-blob` for this repository's release workflow on the tag, and compare `install.sh` with the tree's own before running it.
